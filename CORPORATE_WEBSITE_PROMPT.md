# Corporate Website Setup Prompt for APTYOU SERVICES PRIVATE LIMITED

## Project Requirements

Create a professional corporate website for **APTYOU SERVICES PRIVATE LIMITED** using basic HTML files only (no frameworks like Next.js or React). The website should be simple, clean, and professional.

### Company Information
- **Company Name:** APTYOU SERVICES PRIVATE LIMITED
- **Domain:** aptyou.one (hosted on GoDaddy)
- **Registered Address:** 15/367, Kurumbathur, Thirunavaya, Malappuram, Kerala, India - 676301
- **Git Repository:** https://github.com/apyouservices/aptyou-website.git

### Brand Identity
- **Primary Color:** Coral (#FF6B35)
- **Secondary Color:** Cyan (#0099CC)
- **Accent Color:** Gold (#FFB300)
- **Background:** Warm (#FFF9F7) - 5% coral + white
- **Font:** Inter (Google Fonts)
- **Typography:** Clean, professional, readable

### Required Pages (Basic HTML Files)

1. **index.html** - Homepage
   - Hero section with company name and tagline
   - Brief company overview
   - Key services/products overview
   - Call-to-action sections
   - Professional, trustworthy design

2. **about.html** - About Us
   - Company mission and vision
   - Company history/background
   - Core values
   - Team overview (if applicable)
   - Why choose us

3. **services.html** or **products.html** - Services/Products
   - List of services or products offered
   - Brief description of each
   - Link to AptyRead (if applicable)
   - Other services/products

4. **contact.html** - Contact Us
   - Company address (full registered address)
   - Contact email(s)
   - Contact form (optional, can be simple HTML form)
   - Social media links (if applicable)
   - Map location (optional)

5. **privacy.html** - Privacy Policy (if needed)
   - Standard privacy policy for corporate website

6. **terms.html** - Terms of Service (if needed)
   - Standard terms of service

### Design Requirements

- **Layout:** Clean, modern, professional
- **Responsive:** Mobile-friendly (works on all devices)
- **Navigation:** Simple header navigation with all pages linked
- **Footer:** 
  - Company name and address
  - Quick links to all pages
  - Copyright notice
  - Social media links (if applicable)
- **Color Scheme:** Use brand colors (Coral, Cyan, Gold) sparingly and professionally
- **Images:** Placeholder-friendly, can add real images later
- **SEO:** Basic meta tags for each page (title, description)

### Technical Requirements

- **Pure HTML/CSS/JavaScript** (no frameworks)
- **CSS:** Can use inline styles, `<style>` tags, or separate CSS file
- **JavaScript:** Minimal, only if needed for basic interactivity
- **Structure:** Well-organized, semantic HTML5
- **Accessibility:** Proper heading hierarchy, alt text for images, semantic HTML
- **Performance:** Optimized, fast-loading

### Additional Files Needed

- **styles.css** (optional) - Main stylesheet
- **README.md** - Project documentation
- **.gitignore** - Git ignore file
- **robots.txt** - For SEO
- **sitemap.xml** - For SEO (can be basic)

### Content Guidelines

- **Tone:** Professional, trustworthy, clear
- **Language:** English
- **Target Audience:** Business partners, potential clients, stakeholders
- **Purpose:** Establish credibility, provide company information, enable contact

### Deployment Notes

- Website will be hosted on GoDaddy (aptyou.one)
- Should be easy to deploy (just upload HTML files)
- No build process needed (static files only)
