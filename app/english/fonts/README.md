# English learner typography

Andika Regular and Bold, version 7.000, are unchanged copies of the files already used by the native AptyRead app at `E:/aptyread_new/assets/fonts/Andika/`.

Copyright (c) 2004–2025 SIL Global. Distributed under the SIL Open Font License 1.1. The complete licence is embedded in both font files and copied verbatim to `public/english/fonts/Andika-OFL.txt`.

Official design notes: https://software.sil.org/andika/design/

The English layout loads these locally with `next/font/local`. The service worker saves the emitted font assets together with the app. Use the `--font-andika` token throughout learner text, letter/word displays, and SVG tracing guides. The AptyRead wordmark retains the website's brand typography.
